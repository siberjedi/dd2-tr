DD2TR — Dragon's Dogma 2 Turkish Localization v1.0
====================================================

TARGET GAME VERSION: 4.1.0 (build 25920212, October 2026)

INSTALL
1) Download REFramework nightly (01421 or newer):
   https://github.com/praydog/REFramework-nightly
   Extract dinput8.dll into the game folder:
   ...\steamapps\common\Dragons Dogma 2\

2) Create a folder named "pak_mods" in the game folder (if missing).

3) Copy DD2TR.pak into pak_mods.

4) Launch the game. (Close the REFramework window if it appears.)

UNINSTALL
- Delete pak_mods\DD2TR.pak.

NOTES
- Free mod; do not sell.
- 198 message files remain English (their IDs changed in the latest game patch).
- AI-assisted translation; some lines may have tone inconsistencies.
- Game updates may break this mod.

Project: https://github.com/siberjedi/dd2-tr
